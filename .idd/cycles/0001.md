reviewer が指摘して未対応のもの: claim bundle の項目が claim を指すかの検査(C9 の前に要る)。大域表が 1 つで、protocol 間・ファイル間の同名(例: 2 つの protocol の `step`、`phase_leak.naru` と `smoke.naru` の `Store`)が E012 になる — 29 ファイルの Model を移植する前に module / protocol ごとの名前空間が要る。型引数付き宣言(`record R<T>`、`fn f<T>`)・Constants・interface binding・`observe` / `emit`・引数付き scenario の構文が無い(Constants と binding の形は Statements backend の前に決める)。Int リテラルは前置 `-` のみ、`iff` なし。字句解析は ASCII のみ(`Δ` は書けない。naru では `delta` と書く)。
