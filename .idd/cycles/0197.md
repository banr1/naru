- 事実: 手書きの `hreadBound` の命題は `fgSafetyProgressDeadline` 以後の読みについての主張で、その期限は `rGST + 1 + (1 + (d + k + 5)(7 gap + 22 + 4 extra))` round。`SetupWellFormed` の最小値(`d = 2`、`k = 4`)、gap 1、extra 0、GST 0 でも 321 round = 時刻 3858(`R = 3`、Δ = 1)。命題の slot の範囲(`openingSlot(D) + 1 = 964` 以上)もまるごとその先にある。生成 Model の run の費用は horizon 300 で 8 秒、600 で 103 秒(tick の費用が tree の大きさの 3〜4 乗で増える。手書き Model と同じ性質)なので、時刻 3858 に届く run は `properties` の群の予算(≤ 5 分)にも、現実的な時間にも収まりません。期限を外した診断(判定ではない)では、固定設定 9 run の honest の全読み・全投票について bound は一度も破れていません。
